Калькулятор позиции 

Расчёт выполняется по текущей глубине стаканов обеих бирж: объём ограничен встречной ликвидностью, цена — VWAP задействованных уровней. Net edge = маржа после комиссий обеих площадок и буфера проскальзывания. Положительное значение не гарантирует прибыль: спред может исчезнуть до исполнения. Комиссии задаются в bps (5 bps = 0.05%). Интерфейс работает только в dry-run и не отправляет ордера.
